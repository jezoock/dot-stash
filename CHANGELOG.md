# Changelog

All notable changes to this project are documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html): while the version is 0.x, a minor version may break the API (the breaking changes are listed with what to do).

The readme of each component (`components/core/<component>/readme.md`) ends its hand-written part with a **Changed** note: the changes of that component in detail.

## [Unreleased]

The remaining work, split into small tasks (bugs, accessibility checks, browser support, components, theme, tooling, release and the owner actions outside of the repository), is listed in [docs/backlog.md](docs/backlog.md), in French.

### Added

- **`ds-range`**: enhances a native `<input type="range">` written in it, which stays the slider (its role, name, keys, value and form): a track filled up to the value, from the `--ds-range-fill` custom property (a percentage the component sets), and optionally up to a second value (`buffer`, `--ds-range-buffer`: the part of a video loaded already). It follows the user's events, the attributes of the input, a disabled fieldset and a form reset; `refresh()` reads a value set by a script. `labels.valueText` (a template: `{value}`, `{min}`, `{max}`, `{percent}`) or `formatter` (a function) give the input an `aria-valuetext`. A skin in the `default` theme (`scss/themes/default/components/_range.scss`), with its custom properties (`--ds-range-thumb-size`, `--ds-range-fill-color`…). See its [readme](components/core/range/readme.md).

## [0.1.0] - 2026-11-10

The first release of the library, from the original code of the `main` branch (commit `c49521b`, version 0.0.1): a standalone library of light-DOM web components (Stencil 4.45) and a SCSS theming toolkit, with no runtime dependency, no external service, one neutral theme, accessible components, and unit, stylesheet and browser tests.

It stays 0.x on purpose: only Chromium is tested automatically (unit, stylesheet and browser tests in CI). Firefox, Safari and the screen readers are not verified yet; the minimum browser versions of the [README](README.md#browser-support) come from the compatibility data of the features the code uses, not from tests.

### Added

- **Components**: `ds-alert` (an inline message with an opt-in live region), `ds-badge` (a label or count with a label for assistive technologies), `ds-loader` (a loading indicator with the semantics of a progress bar), `ds-back-to-top` (a link back to the top that brings the focus there), `ds-field` (a form field around a native control: label, hint, error message, character counter, password toggle, prefix and suffix), `ds-breadcrumb` (a breadcrumb trail enhanced from the list of the page, with an optional collapse), `ds-pagination` (links or buttons to the pages of a list, with a compact layout below `sm`).
- **Forms**: `ds-toggle`, `ds-toggle-group` and `ds-combo` are form-associated custom elements (`ElementInternals`): they submit their values with their form, a `<label>` names them, a disabled fieldset disables them, a form reset and the history restore their state. New props: `required` and `required-message` on the three, `disabled` on `ds-combo`, `required` on `ds-select`; new read-only properties `validity`, `validationMessage` and `willValidate`, and methods `checkValidity()` and `reportValidity()` on the three; new method `setGroupDisabled()` on `ds-toggle`; new classes `--disabled` (`ds-toggle`, `ds-toggle-group`, `ds-combo`) and `--invalid` (the four), new custom state `:state(user-invalid)` (the three), new custom properties `--ds-toggle-invalid-color`, `--ds-combo-invalid-color`, `--ds-select-invalid-color`; the default theme draws the invalid state in the error color.
- **Accessibility**: the components follow the WAI-ARIA patterns, with roles, names, states, the keyboard and the focus management; each readme has an Accessibility section, and the README a table of the names, roles and keys and a checklist for integrators. New props: `label` on `ds-modal`, `ds-sidebar`, `ds-toggle`, `ds-toggle-group`, `ds-combo`, `ds-select`, `ds-trigger`, `ds-nav`, `ds-nav-item`, `ds-panel-group`, `ds-slider`, `ds-slider-menu`, `ds-icon` and `ds-block`, `labelledby` on `ds-combo`, `ds-select` and `ds-panel-group`, `labels` on `ds-slider`, `toggle-label` on `ds-nav-item`, `item-label` on `ds-slider-menu`, `level` on `ds-title`, `ds-heading` and `ds-panel`, `error-message` on `ds-ajax`; new slots `title` and `description` on `ds-modal`; new methods `setTabbable()` on `ds-toggle`, `setTab()` on `ds-panel`, `refresh()` on `ds-rsp`; new events `ajaxLoaded` and `ajaxError` on `ds-ajax`; `panelShown` and `panelHidden` of `ds-panel` are emitted (they never were). The details are in the [Changed](#changed) section and the readmes.
- **Theme engine**: the design tokens as CSS custom properties on `:root` (`ds-tokens()`, `--ds-<group>-<key>`), token references (`ds-ref()`), `ds-token()`, `ds-token-value()`, `ds-token-name()`, `ds-has-token()` and a `-value` variant of each accessor; a spacing and a radius scale (`ds-spacing()`, `ds-radius()`), `ds-breakpoint()`, `$gradients`; the focus tokens (`$focus`, `ds-focus()`, `ds-focus-ring()`), `ds-reduced-motion()`, `ds-keyframes()`; the breakpoints for JavaScript (`--ds-bp-<label>`, `--ds-bp-labels`).
- **Icons**: the icon set of the engine, SVG images of Lucide 1.60.0 (ISC License) in `scss/engine/icons/`, compiled into the stylesheets as data URIs and drawn as masks in the color of the text: 101 names (those of the former font, then `ok-circle`, `spinner` and `ellipsis`), `npm run build:icons` (generated `$icons`, `--check`), the `--ds-icons-<name>` custom properties, `ds-icon-tokens()`, `ds-icon-property()`, `$icons-notice`, and the licence texts of the icons in the package (`dist/css/LICENSE-icons.txt`). In forced colors, the icons keep the system color of their text.
- **The `default` theme**: neutral (blue primary, slate secondary, gray scale, system font stacks), with a skin per component, the focus indicator, the rules of less motion, and a `.ds-visually-hidden` class.
- **Component custom properties** (the styling API): each component documents its `--ds-<component>-…` properties (`@prop`), set by the theme from the tokens; each readme has a Styling section.
- **JavaScript utilities**: the `tokens` module (`getToken()`, `getBreakpoints()`); `responsive.widthQuery()`, `matchesWidth()`, `watchMedia()`, `watchBreakpoint()`, `watchThemeBreakpoint()`, `isSameBreakpoint()`, `isStylesheetLoad()`; the package entry exports each module as a namespace, `ds`, `debounce`, `throttle`, `uuid`, `AppStatus`, `DsComponentContext` and the public types.
- **Tooling**: Node build scripts (`scripts/build-css.mjs` with `--watch`, `--strict` and `--source-map`, `scripts/build-icons.mjs`, `scripts/dev.mjs`), ESLint (flat configuration with typescript-eslint), Stylelint, Prettier, `npm run typecheck`, and CI (GitHub Actions: build, formatting, lint, types, unit and stylesheet tests, and the browser tests in Chromium).
- **Tests**: Vitest 5 and `@stencil/vitest`: the unit tests in Stencil's simulated DOM, the stylesheet tests (every theme and component stylesheet compiled without a warning, the custom properties, the styling contract, the accessibility rules, the icons, the slots and the paths of the documentation) and the browser tests in Chromium (keyboard, focus, forms, layout, viewport, transitions, accessibility tree, icons). 1369 unit and stylesheet tests and 182 browser tests in this release.
- **Documentation**: the README (requirements, install, use in another project from a built clone, build output, theming, using the components, forms, styling, accessibility, tests, browser support), a readme per component, `docs/propal-archive.md` (the archive branches), and this changelog.

### Changed

- **Icons**: the icons are SVG images drawn as masks: they were the glyphs of an icon font, `ds-icons`, whose files were never in the repository, so that no icon showed and each page requested the missing font files. An icon is a square of 1em: the elements that hold one (`ds-icon`, an icon button, the expand button of `ds-nav-item`) are a little larger than with the fallback glyph of the missing font (0.78em wide). `dist/css/default.css` grew with the skins: 38 KB (6.7 KB gzipped) with the rules of the former font, which drew no icon; 56 KB (8.5 KB) with the SVG icons; 60 KB (9 KB) with the skin of `ds-field`; 67 KB (10 KB) with the skins of `ds-alert`, `ds-badge`, `ds-loader` and `ds-back-to-top`; 74 KB (10.5 KB) with the skins of `ds-breadcrumb` and `ds-pagination`, which draw three more icons (`angle-double-left`, `angle-double-right` and `ellipsis`).
- **Responsive**: the JavaScript follows the breakpoints with media queries (`matchMedia()`), no longer with `window.innerWidth` and the `resize` event. `<ds-rsp>` applies a breakpoint change at once, once when the viewport crosses several breakpoints and never within one; it reads the breakpoints from the theme (`tokens.getBreakpoints()`) or from its `breakpoints` attribute (a new value is applied), reads them again when a stylesheet `<link>` loads, emits `breakpointChange` itself (it was declared and never emitted; it bubbles), applies the params of the current breakpoint to the elements subscribed or inserted later, and reads the initial value of a camelCase property from the property. The breakpoint is the same at every whole width. `ds-nav-item` closes its sub-navigation when the viewport crosses `md`.
- **`ds-grid`**: the grid computed the width and paddings of each item in JavaScript, in a flex row; it now writes its props as custom properties (`--ds-grid-cols`, `--ds-grid-h-gap`, `--ds-grid-v-gap`, `--ds-grid-cell-ratio`, `--ds-grid-span`, `--ds-grid-item-ratio`), and CSS Grid lays the items out. The content of the items is where it was, but where that layout was wrong: rows that wrapped, `fluid` items of several columns, incomplete rows with a gap, nested grids, and `ratio` and `cell-ratio`, which did not work (the list is in the [readme](components/core/grid/readme.md)). Every prop can change per breakpoint with `<ds-rsp>`.
- **Forms and controls**: `ds-toggle` and `ds-trigger` (when it is the control) are focusable, with a role, and Enter and Space activate them; `ds-toggle-group` has a role and the arrow keys of a radio group, and its `disabled`, which did nothing, disables its toggles; `ds-combo` has the combobox and listbox roles and the keyboard, and its `dropdown` mode moves the focus to the list; `ds-select` disables its native select and hides the label of its box from assistive technologies. The focus outline of `ds-toggle` is out of its 0.4 s transition, and so is its visibility (it transitioned `all`: a toggle shown or hydrated could not take the focus in its first frame); `ds-toggle` no longer removes the focus outline.
- **Overlays**: `ds-modal` takes the focus and keeps it while shown, and gives it back; `ds-sidebar` is a `complementary` landmark, inert while hidden, and `show()` and `hide()` move the focus; `ds-toaster` renders a live region and an `aria-hidden` toast box, and the countdown of `displayToast()` pauses while the pointer is over the toasts or the focus is in the toaster (WCAG 2.2.1, it ran to its end), and its box is never wider than the viewport less 2rem (it overflowed a 375 px screen); `ds-tooltip` shows its message on the keyboard focus, hides it on Escape and 300 ms after the pointer leaves, and stays while the pointer is over it.
- **Navigation and content components**: `ds-panel-group` of tabs renders a tab list and selects its first panel when none is expanded; `ds-panel` wraps its `title` slot in a control, makes its collapsed content inert and no longer clips an expanded content; `ds-slider` has inert slides out of view, a live region and a rotation button with `params.autoplay`, `stop()` and `play()` work, and it no longer hangs when a slide does not run; `ds-nav` is a navigation landmark and a list; the expand button of `ds-nav-item` has a name, `aria-expanded` and Escape, and the collapsed sub-navigation is hidden; `ds-ajax` sets `aria-busy`, moves the focus to the loaded content or announces it, and shows `error-message`.
- **Less motion**: with `prefers-reduced-motion: reduce`, the theme ends the transitions and animations at once (the loading indicators keep turning, more slowly), `ds-sidebar`, `ds-toaster` and `ds-slider` drop their slides, and the automatic rotation of `ds-slider` does not start. The components that wait for a transition (`ds-sidebar`, `ds-toaster`, `ds-panel`, `ds-slider`, `ds-nav-item`) no longer hang when it does not run.
- **Tests**: the tests run with Vitest and `@stencil/vitest` instead of Stencil's test runner (Jest, deprecated since Stencil 4.43); `npm run test.watch` is now `npm run test:watch`; `npm run test:e2e` (Stencil end-to-end tests with Puppeteer, which had no test) is removed, for `npm run test:browser` (the browser tests, with Playwright); `npm run typecheck` is new, and `format` and `format:check` cover the `.mts` files. Dev dependencies: `jest`, `jest-cli`, `@types/jest` and `puppeteer` are removed; `vitest`, `vite`, `@stencil/vitest`, `@vitest/browser-playwright`, `playwright` and `@types/node` are added, at exact versions.
- **Dependencies**: Stencil 4.21 → 4.45.2, TypeScript 5.8 (the version Stencil compiles with), ESLint 10, Sass 1.107; `@stencil/sass` 3.3.
- **Package metadata**: the version is 0.1.0, with a description, keywords, the repository, its home page and its issues.

### Deprecated

- `setStyles()` of `ds-grid-item` and its `DSGridItemStyles` type: the grid no longer calls it (it still writes the given styles).
- `debounce-delay` of `ds-rsp`: ignored, with a console warning.

### Removed

- **Components**, archived on `archive/propal` (`archived/`, see [docs/propal-archive.md](docs/propal-archive.md)): `ds-video`, `ds-marquee` and `ds-rating-list`, the demo (`ds-main`, its theme switcher and runtime color control) and the `legacy` theme. `ds-button`, added during this release and archived before it, is not part of it: `ds-trigger type="button"` renders the `.ds-button` class, which the theme skins.
- **Components without replacement**: `ds-app` (its helpers are the utility modules, and `ds-rsp` is the only breakpoint manager), `ds-dropdown` and `ds-dropdown-item` (merged into `ds-combo`: their slotted items had no selection behavior).
- **External integrations**, archived on `archive/external-integrations`: the back-office content editor (`pronto-content-admin`, its `pronto-*` form components and `ds-*-configurator` components, `ds-html-editor`, `ds-input-date`, `ds-input-number`, `ds-input-modal`, `ds-json`, `ds-filemanager`, the CMS, product, category and tag searches, `ds-html`, `ds-media`, `ds-password`), the REST client of a shop (`typescript/prestapi.ts`), the map components (`ds-map`, `ds-map-location`, `ds-map-marker`, `ds-info-window`), the infinite-scroll product list (`ds-product-list`), the shop theme styles and their npm packages.
- **Code**: the Propal project copy (`toSort-propal/`, archived), the gulp build, dead utilities and commented-out code, debug logging, orphan stylesheets, the JSON bridge, the icon font, the `es2015` and `es2017` fields of `package.json`, the unused `DsBlockTypeToTag` map of `ds-block` (internal).

### Fixed

Bugs of the original code, fixed in this release (the component readmes give the details):

- `ds-modal`: `hide()` (Escape, a mouse down outside) emitted `modalClose` without closing the modal; the toggle request read `event.details`; a modal rendered with `shown` was not set up; closing a modal removed the body class while another one was shown, and wrote the body's inline `overflow`.
- `ds-toggle`: a checkbox, a switch or an icon toggle could not be unchecked; `setProps()` only wrote truthy values; a toggle's own `type` was replaced by its group's. `ds-toggle-group`: unchecking a toggle left the value undefined; later changes of its `name`, `type` and `mods` were not passed on to its toggles, nor to the toggles added later.
- `ds-toaster`: the class list was built with `ds-title` and never rendered; the transition handler was not bound; it rendered a `ds-toast` element that does not exist; the `middle` and `bottom` positions equalled `top`; `max-displayed-toast` was ignored.
- `ds-ajax`: the URL suffix was dropped after an existing query string, a lone `?` was appended, an HTML page always failed (parsed as JSON), and nothing loaded without `on`.
- `ds-block`: the `modal` context gave the `block` class; the classes and the header and footer wrappers were computed after the first render (no host class, `ds-block__body` for a named block, unwrapped header and footer), and the wrappers of the unnamed blocks were hidden.
- `ds-heading`: the titles were wrapped in a non-existent `hlgroup` element (now `hgroup`); the sub-title slot was rendered for an image instead of a sub-title.
- `ds-rsp`: its resize listener was never removed; `data-rsp-init` was set as a property, so initialised subscribers were not skipped; it crashed without breakpoints.
- `ds-sidebar`: `toggle(false)` showed a hidden sidebar; a dead passive `touchmove` listener (now `overscroll-behavior: contain`); a hidden sidebar stayed on the screen.
- `ds-grid`: the width of a `fluid` item missed a closing parenthesis (browsers dropped it), and a unitless gap made it invalid.
- `ds-combo`: a crash without options or with an invalid JSON; a pre-selection by value or name was never reached; its id changed with the number of combos; its outside-click listener was not removed.
- `ds-slider`: `stop()` let one more slide go and `play()` did nothing; the index of the current slide went below 0; a slide waited forever for a `transitionend` that did not come; a Stencil warning at its load; with `params.index`, the slide shown was the first one while the current slide (its dot, its buttons, its events) was that of the index.
- `ds-panel`: `panelShown` and `panelHidden` were never emitted; `ds-panel-group` took the panels of its nested groups.
- `ds-select`: a disabled select could be focused and changed.
- `ds-trigger`: without `on`, it never fired; a disabled trigger still called its action.
- Utilities: `ajax.get()` added a second `?`; `ds-breakpoint()` wrote `768pxpx` for a width in px; `break-p('min')` wrote an invalid media query.
- The build: Stencil wrote absolute paths of the machine into the published collection and types; the dev build stopped on duplicated tags of the Propal copy and on Sass import errors.

### Security

- The hard-coded keys and tokens of the original code are removed: a key of a map service, the webservice key of a shop, the key of a rich-text editor service, and an admin token and the name of an admin folder. The git history was purged of their values (they read `***REMOVED***`), but they were public before: rotate them, rename the admin folder, and check that no clone or fork of the former history remains (owner actions, outside of the repository).
- No runtime dependency and no external service: the library loads nothing from a third-party host (the icons are in the stylesheets, no font file, no CDN, no service worker that would load Workbox from a CDN).
