## Library code in `archived/`

Commit `8e754e2` of `archive/propal` adds `archived/`: code removed from the development branch, copied unchanged from
commit `f4ff816` of `claude/intelligent-pasteur-rwiqsn`, the last one before the removal. Each folder mirrors the repository
root (`archived/components/ds-button/components/core/button/button.tsx` was `components/core/button/button.tsx`), and
`archived/README.md` lists what each part depended on.

- `archived/components/<tag>/`: the components `ds-button`, `ds-video`, `ds-marquee` and `ds-rating-list`, removed from
  the library: their folders (`.tsx`, types, structural `.scss`, specs, readmes) and their skins of the `default` and
  `legacy` themes. The utilities they used (`props`, `env`, `debounce`) stay in `components/utils`, and the `.ds-button`
  skin stays in the `default` theme: `ds-trigger type="button"` renders that class.
- `archived/demo/`: the demo, removed from the development branch: `components/demo` (`ds-main`) and the two dev pages
  that rendered it (`index.html`, `components/index.html`), with their theme switcher and runtime color control. The
  dev pages now only load the build and the `default` theme.
- `archived/themes/legacy/`: the whole `legacy` theme (`scss/themes/legacy/`), removed from the development branch, which
  now has one theme, `default`. It configures the engine of that commit with its own values and tokens; its font files
  were never in the repository. The tests that checked it are in `components/sass.spec.ts` of commit `f4ff816`.

## Propal archive (`toSort-propal/`)

`toSort-propal/` (317 files copied from the "Propal" project) was removed from the development branch.
It is preserved on the branch **`archive/propal`** (commit `997b49e`).

When recovering a component, move it into `components/core/`, fix its imports,
and do not add `toSort-propal` back to `tsconfig.json`.

### Why it was removed

- It was listed in `tsconfig.json` `include`, so Stencil compiled it with the library.
- `cart/` and `cart-2/` define the same 15 tags, and `form/` redefines `ds-select` (`components/core/select`),
  `ds-input-date` (also defined at the time by a form widget that has since been removed) and `ds-input`
  (also in `form-store/`). `npx stencil build --dev` stopped with 18 "Component Tag Name … Must Be Unique" errors.
- Most of it imports modules that do not exist in this repo: `@stencil/redux`, `redux`, `dayjs`, `jwt-decode`,
  `_redux/*`, `api-types`, `interfaces`, `models/*`, `utils` (`DS_setTranslations`, `DS_formatPrice`,
  `DS_eventDispatch`, …), `ui/*` enums, and components such as `ds-button`, `ds-loader`, `ds-alert`, `ds-snackbar`.
- Imports of `typescript/dot-stash` use relative paths written for a deeper folder and do not resolve.

After removal, the dev build only reported the known Sass import errors.

components (Task 3).
